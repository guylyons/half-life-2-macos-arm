# Half-Life 2 arm64 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `nillerusr/source-engine` as native arm64 on macOS 26, fix it until Half-Life 2 plays, and ship it as `Half-Life 2.app` reading the Steam data in place.

**Architecture:** The engine tree lives in `source-engine/` (git clone) with fixes as commits on local branch `macos-arm64`, exported to `patches/`. `build.sh` configures and builds with waf and installs into a staging prefix; `make-app.sh` turns that prefix into an app bundle whose launcher script sets up a writable mod directory that mounts the Steam content by absolute path.

**Tech Stack:** waf (python3), Apple Clang, Homebrew sdl2-compat/freetype/fontconfig/jpeg-turbo/libpng/curl/zlib/bzip2/opus, OpenGL 4.1 via togl, bash.

**Spec:** `docs/superpowers/specs/2026-09-09-hl2-arm64-port-design.md`

## Global Constraints

- Nothing under `~/Library/Application Support/Steam` is ever written.
- Engine is built 64-bit arm64 release (`-T release`, no `-4`).
- Game data is the `steam_legacy` ("Pre-25th Anniversary Build") branch; the anniversary layout (`hl2_complete/` present) is unsupported and must be detected.
- Writable state goes to `~/Library/Application Support/Half-Life-2-arm64/`.
- The app must run with no Homebrew on `PATH` (SDL2 bundled).
- Every engine fix is a commit on `source-engine` branch `macos-arm64` and exported to `patches/NNNN-*.patch`.

```

  Half-Life 2.app/        output (untracked)
  README.md

```

```bash
#!/bin/bash
# Build the arm64 Source engine and assemble Half-Life 2.app.
# Usage: ./build.sh [deps|patch|configure|build|install|app]...  (default: all)
set -euo pipefail
ROOT="$(cd "$(dirname "$0")" && pwd)"
ENGINE="$ROOT/source-engine"
STAGE="$ROOT/stage"
JOBS="$(sysctl -n hw.ncpu)"
BREW="$(brew --prefix)"
# keg-only packages need explicit pkg-config paths
export PKG_CONFIG_PATH="$BREW/opt/zlib/lib/pkgconfig:$BREW/opt/bzip2/lib/pkgconfig:$BREW/opt/curl/lib/pkgconfig:$BREW/opt/jpeg-turbo/lib/pkgconfig:$BREW/lib/pkgconfig:${PKG_CONFIG_PATH:-}"

deps() {
  for p in sdl2-compat freetype fontconfig jpeg-turbo libpng curl zlib bzip2 opus pkg-config; do
    brew list --versions "$p" >/dev/null 2>&1 || brew install "$p"
  done
  xcode-select -p >/dev/null
}

patch() {
  [ -d "$ENGINE/.git" ] || git clone --recursive --depth 1 https://github.com/nillerusr/source-engine.git "$ENGINE"
  cd "$ENGINE"
  if ! git rev-parse --verify -q macos-arm64 >/dev/null; then
    git checkout -q -b macos-arm64
    if ls "$ROOT"/patches/*.patch >/dev/null 2>&1; then git am "$ROOT"/patches/*.patch; fi
  fi
  git checkout -q macos-arm64
}

configure() {
  cd "$ENGINE"
  python3 waf configure -T release --prefix="$STAGE" --build-games=hl2 --enable-opus
}

build() { cd "$ENGINE" && python3 waf build -j"$JOBS"; }
install() { cd "$ENGINE" && rm -rf "$STAGE" && python3 waf install; }
app() { "$ROOT/make-app.sh"; }

if [ $# -eq 0 ]; then set -- deps patch configure build install app; fi
for step in "$@"; do "$step"; done
```

- [ ] **Step 4: Write `launcher.sh`**

```bash
#!/bin/bash
# Half-Life 2 launcher for Apple Silicon (engine: nillerusr/source-engine, arm64).
# Reads game data in place from Steam; writes saves/config to HL2_BASE.
set -u
HERE="$(cd "$(dirname "$0")" && pwd)"
RES="$HERE/../Resources"
STEAM="${HL2_STEAM_DIR:-$HOME/Library/Application Support/Steam/steamapps/common/Half-Life 2}"
BASE="${HL2_BASE:-$HOME/Library/Application Support/Half-Life-2-arm64}"
DRY=0
if [ "${1:-}" = "--dry-run" ]; then DRY=1; shift; fi

fail() {
  echo "$1: $2" >&2
  [ -n "${HL2_NO_ALERT:-}" ] || osascript -e "display alert \"$1\" message \"$2\" as critical" >/dev/null 2>&1
  exit 1
}

[ -f "$STEAM/hl2/hl2_misc_dir.vpk" ] || fail "Half-Life 2 data not found" "Expected the Steam install at:
$STEAM

Install Half-Life 2 in Steam (branch steam_legacy), or set HL2_STEAM_DIR."
[ ! -d "$STEAM/hl2_complete" ] || fail "Unsupported Half-Life 2 version" "This build needs the pre-anniversary game data.
In Steam: Half-Life 2 > Properties > Betas > steam_legacy."

MOD="$BASE/hl2"
mkdir -p "$MOD/bin" "$MOD/cfg" "$MOD/save"
cp -f "$RES/hl2/bin/client.dylib" "$RES/hl2/bin/server.dylib" "$MOD/bin/"
sed "s|@STEAM_HL2@|$STEAM|g" "$RES/gameinfo.hl2.txt" > "$MOD/gameinfo.txt"

cd "$HERE"
if [ "$DRY" = 1 ]; then
  echo "exec \"$HERE/hl2_launcher\" -game \"$MOD\" $*"
  exit 0
fi
exec "$HERE/hl2_launcher" -game "$MOD" "$@"
```

  c. `long double` is 8 bytes on Apple arm64 vs. 16 on Linux aarch64; grep `ivp/` and `vphysics/` for `long double` and `sizeof(long double)`.
  d. Fix with the minimal change, comment naming the symptom, commit.

- [ ] **Step 1: Write `make-app.sh`**

```bash
#!/bin/bash
# Assemble "Half-Life 2.app" from stage/ (waf install prefix).
set -euo pipefail
ROOT="$(cd "$(dirname "$0")" && pwd)"
STAGE="$ROOT/stage"
APP="$ROOT/Half-Life 2.app"
STEAM="$HOME/Library/Application Support/Steam/steamapps/common/Half-Life 2"

for f in "$STAGE/hl2_launcher" "$STAGE/bin/engine.dylib" "$STAGE/bin/launcher.dylib" \
         "$STAGE/hl2/bin/client.dylib" "$STAGE/hl2/bin/server.dylib"; do
  [ -f "$f" ] || { echo "missing build output: $f (run ./build.sh first)" >&2; exit 1; }
done

rm -rf "$APP"
mkdir -p "$APP/Contents/MacOS" "$APP/Contents/Resources/hl2/bin"
cp "$STAGE/hl2_launcher" "$APP/Contents/MacOS/"
cp -R "$STAGE/bin" "$APP/Contents/MacOS/bin"
cp "$STAGE/hl2/bin/client.dylib" "$STAGE/hl2/bin/server.dylib" "$APP/Contents/Resources/hl2/bin/"
cp "$ROOT/gameinfo.hl2.txt" "$APP/Contents/Resources/"
cp "$ROOT/launcher.sh" "$APP/Contents/MacOS/Half-Life 2"
chmod +x "$APP/Contents/MacOS/Half-Life 2"

# Bundle SDL2 (and SDL3 that sdl2-compat dlopens) so Homebrew is not needed at run time.
SDL_SRC="$(otool -L "$STAGE/bin/launcher.dylib" | awk '/libSDL2/ {print $1}')"
if [ -n "$SDL_SRC" ] && [ ! -f "$APP/Contents/MacOS/bin/$(basename "$SDL_SRC")" ]; then cp "$SDL_SRC" "$APP/Contents/MacOS/bin/"; fi
SDL_NAME="$(basename "$SDL_SRC")"
SDL3_SRC="/opt/homebrew/lib/libSDL3.0.dylib"
[ -f "$SDL3_SRC" ] && cp "$SDL3_SRC" "$APP/Contents/MacOS/bin/libSDL3.dylib"
chmod u+w "$APP/Contents/MacOS/bin/"*.dylib
for lib in "$APP/Contents/MacOS/bin/"*.dylib; do
  install_name_tool -change "$SDL_SRC" "@loader_path/$SDL_NAME" "$lib" 2>/dev/null || true
done
# Any remaining Homebrew dylib references are a packaging bug; list them.
if otool -L "$APP/Contents/MacOS/bin/"*.dylib "$APP/Contents/MacOS/hl2_launcher" | grep -q /opt/homebrew; then
  echo "WARNING: Homebrew dylibs still referenced:" >&2
  otool -L "$APP/Contents/MacOS/bin/"*.dylib | grep /opt/homebrew >&2
fi

[ -f "$STEAM/hl2/resource/game.icns" ] && cp "$STEAM/hl2/resource/game.icns" "$APP/Contents/Resources/Half-Life 2.icns"

cat > "$APP/Contents/Info.plist" <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>CFBundleName</key>            <string>Half-Life 2</string>
  <key>CFBundleDisplayName</key>     <string>Half-Life 2</string>
  <key>CFBundleIdentifier</key>      <string>local.halflife2.arm64</string>
  <key>CFBundleVersion</key>         <string>1.0</string>
  <key>CFBundleShortVersionString</key> <string>1.0</string>
  <key>CFBundlePackageType</key>     <string>APPL</string>
  <key>CFBundleExecutable</key>      <string>Half-Life 2</string>
  <key>CFBundleIconFile</key>        <string>Half-Life 2</string>
  <key>LSMinimumSystemVersion</key>  <string>12.0</string>
  <key>LSArchitecturePriority</key>  <array><string>arm64</string></array>
  <key>NSHighResolutionCapable</key> <true/>
</dict>
</plist>
PLIST

codesign --force --deep --sign - "$APP" >/dev/null 2>&1 || true
echo "Built $APP"
```
